Upload

      
    

    
Controls how run data is uploaded to S3 and how failed uploads are retried. Changes apply to the next upload.

    

      
      
      

        

          

            
Upload engine

            
boto3: one file at a time with live progress. s5cmd: several files at once (faster for runs with many files); progress moves per finished file. s5cmd must be in the images (after an update that adds it, run docker compose build && docker compose up -d); until then boto3 is used
