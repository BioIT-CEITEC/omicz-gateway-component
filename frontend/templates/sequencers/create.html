{# Setup guide — new machine #}

Setting up a new machine? Follow these steps first:

  1. Choose a short machine name, e.g. machine-7.
  2. Add to .env in the project root:
    Windows: MACHINE_7_PATH=C:\Output\Machine7
    Mac/Linux: MACHINE_7_PATH=/Volumes/SequencerData/Machine7
  3. Add a volume under backend, worker, and watcher in docker-compose.yml:
    - ${MACHINE_7_PATH}:/runs/machine-7
  4. Restart the app so Docker picks up the new volume mapping.
  5. Enter the location above: /runs/machine-7 — always use the /runs/ prefix.
